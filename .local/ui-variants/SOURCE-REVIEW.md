- LSP is exactly 7 where this target has no demonstrated substitution. React variants and the rendering suite receive 10 for the shared public behavioral assertions (including fallback).
- Fixed orchestration/grammar/shape steps receive OCP 6; no score is raised to excuse a fixed step sequence. Declaration-only vocabulary is evaluated as data rather than an orchestrator.
- Pure export barrels receive information-hiding 0: they control a surface but implement no hidden behavior. Thin declaration records receive 5; complete validating schemas receive 10.
- Native host/composition files receive testability 5 for partial injected owners plus ambient infrastructure; their infrastructure failures/recovery boundaries receive 8 where applicable. The pure core and declaration files contain no ambient I/O.
- ISP checks include passed-through use. Headless and rendering asset/token/template roles were narrowed to the methods actually consumed. Declaration files without behavioral ports carry no fat-port finding.
- No unchecked casts or `any` were introduced. Const assertions on literal test/manifest data do not assert an unverified runtime shape. Lint enforces cognitive complexity <=2 for every function.
- External effects (file writes, process exit status) are reviewed under retry/cleanup; the immutability row judges retained records and shared in-process state. Local data collections in the headless path are constructed immutably.
- Fixed grammar or notation choices remain OCP deductions even where appropriate to this mission. No silent exceptions or pre-awarded perfect totals.
