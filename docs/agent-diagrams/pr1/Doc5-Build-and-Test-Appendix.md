# Build and verification
1. Freeze counts; one fresh scoped plan pressure test, eight-minute timeout. Verify findings; one fix, words/lines growth ≤20%; no reaudit.
2. Implement contracts→language→layout; explicit return types, responsibility/recovery TSDoc, readable names; Sonar ≤2; per-file evidence >144/160 using literal rubric.
3. Extend existing tests where possible. Budget: at most four new focused test cases across existing Model, Language and Layout suites. Assertions cover invalid values/non-grid rejection; full read/print + set/reset; collection/section/group scope retention; measured unequal grids and deterministic direction. Parameterized vectors allowed. No E2E tests.
4. Run typecheck, lint, format, architecture, relevant suites. DSL-author three probes through real local service: compact ER, nested illustrated comparison (admitted media deferred PR3), sequence alternatives. Record receipts/readouts/browser captures; initial probes prove semantics, final polish gate belongs PR2–5.
5. A1 spec/coding and A2 test correctness: one round, eight minutes each, ≤5 source targets each. A2 attempts three assertion counterexamples. Verify before one findings-only fix; no reaudit. One extra delegate-realignment step only if scope deviation.
6. Commit PR with scope, checks and honest residuals. No automatic merge. No invented per-file score or claim that sampling certifies all files.
