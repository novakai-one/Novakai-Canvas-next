# Ownership and CRUD
|Action|Owner path|Effect|
|---|---|---|
|Create or edit semantic wire|Language→Authoring→Layout|Labelled inspected geometry; exact identity retained|
|Request attachment side|Existing DSL connect properties|Hard authored attachment respected|
|Reset automatic route|Existing DSL reset route|Native/local candidate policy recalculates|
|Read/print|Language|Agent sees semantic wire and routing intent, no coordinates|
|Locked collision|Layout→Authoring failure|Existing collection remains committed unchanged|

No persistence shortcut. Scene/version keys change for routing policy. Group boundaries remain traversable as existing semantics permit; group content/header obstacles remain protected.
