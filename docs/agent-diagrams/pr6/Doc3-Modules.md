# Modules and contracts
|Owner|Contract|Outcome|
|---|---|---|
|Templates|Admit/instantiate generic recipe with exact pins|Editable expansion; no hidden image-specific behavior|
|Language/Authoring|Real create/read/meaningful patch or replace|Canonical semantics plus inspected geometry committed|
|Presentation/Layout/Canvas|Bounded32-section projection/scene|32 permitted within aggregate limits;33 rejected explicitly|
|Export|Same projection budget|No stale10-section hard rejection or misleading scale calculation|
|Evidence runner|Visible browser controls and screenshots|Operational acceptance, not an E2E test suite|

Author two variants per family during development; third independently after public intent/metric freeze. Corpus slots are in CORPUS.md. Rendering recipes must not inspect titles/IDs/subjects to choose geometry.

Recipe expansion remaps namespaces; content changes through ordinary DSL. No parameter-substitution API is introduced.
