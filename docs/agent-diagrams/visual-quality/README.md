## Overall done

1. Three structurally distinct original examples for each family: story/educational infographic, comparison grid, flow/SOP, ER, module/interface/function, sequence, state, tree/mindmap. Work in small batches; all 24 are required only at the final exit.
2. Native React Flow nodes/edges; figures are admitted assets inside editable nodes, never full-diagram background posters. No subject-specific renderer or reference-image coordinate map.
3. Each readable DSL source ≤300 physical lines. Split coherent diagrams/collections without severing meaning or compressing formatting. At least one small mixed-type collection demonstrates composition; the whole showcase need not share one canvas.
4. Viewer can trace processes, distinguish comparison dimensions and read engineering contracts, member anchors, cardinalities and labelled wires. Hierarchy, imagery, typography, spacing and routing achieve the qualities in References.md.
5. Actual DSL create/read/edit, longer content, live agent update, refresh, service restart and real exports retain meaning and accepted geometry. Visible browser verification is mandatory; headless checks alone never establish the human result.
6. Stage PRs pushed, bounded reviews/fixes recorded, relevant correctness and coding gates satisfied. No invented standards scores or declaration of benchmark success from counts alone.

Internal helper names and wire-up choices in Doc6 are estimates, not auditor requirements. Public acceptance/return contracts, invariants, responsibility boundaries and coding standards are requirements. Any new generic feature must have reusable evidence during its stage, not only at final acceptance.
