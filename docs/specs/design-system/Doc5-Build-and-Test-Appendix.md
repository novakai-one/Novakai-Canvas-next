**Build:** typed sources/primary controls → alias/recipe/contrast resolver → UI/diagram/theme projections → artifact compiler/style gate → real hash/filesystem/DOM bindings → reusable React/panel primitives → generated snapshots.
**Frozen budget:14 behavioral cases / five suites.** Fast public-contract/component cases only; no E2E. Actual browser visual/focus/responsive state audits remain mandatory Part2, separately per UI section.

Test13 exercises installer adapter contract with replaceable target; no native interaction proof is inferred from DOM simulation.

Build: A1 fidelity/standards + A2 assertion correctness≤3 challenges; each≤8min and≤5 targets; capability scope only; one verified findings-only fix, no re-audit.
