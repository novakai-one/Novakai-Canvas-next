# Increment A implementation contract

Layout owns a pure retained-support preflight for offline audit consumers and future embedding consumers. One public operation takes the semantic spec and its built reservation scene, returning a support ledger or structured admission failure. It does not authorize geometry, routing-policy, UI, persistence, or B/C/D changes. All intermediate records remain in Layout core; public outcomes are declaration-only records. The ordinary builder serialization and measured numeric operations must remain identical.

Stable identities originate at construction (owner, axis, structural ordinal, merged origins); public coordinate-bearing road IDs remain opaque references. Retained routing/allocation remain authoritative. Failure is deterministic data; callers own retry by reconstructing the inputs. No events, host services, ambient state, external solvers, or adapters are needed.
