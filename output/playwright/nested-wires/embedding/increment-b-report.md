`embedNestedSupports` is a public, typed, pure query against a **reservation** scene, useful for independently reproducing the builder's result with the saved A inputs. `preflightNestedSupports` retains that reservation-input contract. The active builder shares the compiler/materializer without replaying reservation or routing.
