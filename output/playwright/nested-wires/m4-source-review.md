## Audit programs and evidence scope

As explicitly documented by the M1.5/M2/M3 source reviews, standalone acceptance CLI/MJS/Python programs are terminal audit tooling, not application APIs assigned the application-source scores. Their assertion and I/O failures intentionally terminate the process. No new exception to lint or application standards is introduced here. `pnpm check` checks JavaScript with the existing ≤2 ceiling and passes all 208 tests. There are zero added `.test.ts` files.

`verify-lanes.mjs` checks public-contract output, exact pins/margins, every segment pair, containment, right-hand lanes, assigned gate crossings, complete serialization and canonical scene equality; it invokes the amended visual gate. `verify-m4-pin-preservation.mjs` reads `2f9b762` from git and independently builds only the six permitted replacements. `verify-m4-visual-budget.py` computes angle and intersection kind, requires a registered containing junction, retains nonqualifying crossings, enforces ≤6, and reports every excluded record with reason. Built-in negative controls cover shallow angles, overlaps, unregistered crossings and seven budgeted crossings. `verify-m4-evidence.py` reconciles canonical output, browser samples, selection, counts, PNG hashes and test evidence. The operation meter asserts instrumented/uninstrumented identity; oracle graph search exists only in independent evidence tooling. Both browser runners use isolated headless CLI sessions and the already-running Vite.

## Worst three limitations

1. Projection now has three interacting geometry cases (joins, fixed rank doglegs, terminal fans). This is the weakest readability score; independent global geometry/preservation checks are essential evidence.
2. Pin-row capacity is finite: 15 left-side or 31 top-side pins with pitch-6 end margins. The README's 25-wire costs are extrapolations, not an admission guarantee. Construction probe doubles nodes but retains 26 requests.
3. Host browser APIs remain ambient. Readiness requires Chromium/font/frame measurements; the suite does not imply universal device timing. Selection correctness is separately checked against all scene geometry and camera fields.
