# Seven-node visual evidence

Captured during the seven-node milestone; this PR retains all 99 two-wire screenshots plus the overview and three section views. Open `index.html` locally for the complete gallery. Live links assume `pnpm prototype:roads` on port 5188.

`scene.json` and `proofs.json` record the exact generated geometry. `verification.json` and `click-results.json` contain geometry/direction and browser pointer checks. The measurements are historical numeric-expression counts, not CPU instruction counts or current-run timings; see the scope and exclusions in `docs/maintenance/seven-node-road-proof.md`.

The reference instrumentation and temporary transformed modules remain local task artifacts; they are not part of the application. The nested milestone has separate evidence in `../nested/`.
