# Shipped recipe sources — version 1.0.0

| File | Family | Meaning |
|---|---|---|
| er.canvas | er | Typed PK/FK fields and explicit cardinalities |
| modules.canvas | modules | Provided/required ports, interface and function signature |
| sop.canvas | sop | Numbered steps, decision, labelled rework loop |
| mindmap.canvas | mindmap | Rooted hierarchy with annotation |
| sequence.canvas | sequence | Ordered messages and named alternative branches |
| infographic.canvas | infographic | Explanatory cards, lists, roles and labelled references |

Sources follow baseline canvas1. The bootstrap host resolves `paper` once and records an exact theme pin before preset admission. Templates receives the resulting pinned canonical source through its required Language bridge. These files are editable starting content, not already-admitted immutable records. Their actual parsing/rendering is verified in the Language/UI stage, not by Templates' codec fixtures.
